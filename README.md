# 🚗 Car Gallery

A simple and visually appealing **Car Gallery website** built using **HTML and CSS**.
The project showcases a collection of cars along with their ratings and prices in a clean gallery-style layout.

## ✨ Features

* 🚘 Collection of multiple car models
* ⭐ Rating displayed for each car
* 💰 Price information for every car
* 🖼️ Circular car images with styled borders
* 🌄 Full-screen background image
* 🎨 Custom colors, text styling, and shadows
* 📱 Responsive viewport configuration

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
